# Как коммитить в этом проекте

**Формат: только заголовок, без описания.**

```
<префикс>: <что изменилось, коротко, по-русски>
```

Тело коммита, строки `Co-Authored-By` и любые подписи не добавляем. Один коммит — одна законченная правка.

## Префиксы

Всегда маленькими буквами и с двоеточием.

| Префикс | Когда использовать | Пример |
|---|---|---|
| `add:` | новая функция, команда, страница, файл | `add: общий взлёт для всех игроков, запуск раунда с минутой на ставки` |
| `tweak:` | изменение или улучшение того, что уже есть: внешний вид, тексты, настройки | `tweak: тоньше линии рамок и меньше текст плиток` |
| `fix:` | исправление ошибки | `fix: сумма покупки на бирже считается как на сервере, максимум больше не даёт ошибку` |
| `remove:` | удаление функции или файла | `remove: команда goto` |

## Как писать заголовок

- По-русски, одной строкой, без точки в конце.
- Описывайте, что правка делает для пользователя, а не какие файлы затронуты. Хорошо: «категория не дублируется внутри плитки». Плохо: «правки в _home.scss».
- Небольшое изменение — коротко и без громких слов. Заголовок может быть длинным, если иначе непонятно, что именно починили.
- Названия команд и технические слова оставляйте как есть (`resetpass`, `cat`, `/posts`).

## Порядок работы с `master`

1. Перед коммитом запустите проверки: `npx eslint .` и `npx stylelint "_sass/**/*.scss"`. Если трогали Worker, запустите его тесты и пересоберите бандл: `python3 worker/build-bundle.py`.
2. Закоммитьте нужные файлы одним заголовком. Автор — вы сами, без пометок.
3. Подтяните чужие изменения и отправьте свои:

   ```
   git fetch origin master && git rebase origin/master
   git push origin master
   ```

4. Не создавайте лишних merge-коммитов и не пушьте в чужие ветки.

## Что не коммитить

- Временный адрес сервера в `_data/console.yml`: поле `api_url` должно оставаться облачным (`https://anroxcomputers.astronaut0space.workers.dev`).
- Собранные файлы (`assets/js/dist`, `_site`) и тестовые скрипты.

## Памятка

```
add: что появилось
tweak: что стало иначе
fix: что починено
remove: что убрано
```
