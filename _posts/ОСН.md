Отряд Специального Назначения - ОСН
ОСН, специально созданные отряды под различные задачи, они подчиняются ДКБ, ДЗИС и Семье Симато, набирается ОСН из особо отличившихся Офицеров Рыцарей и выше, сотрудники ОСН должны быть готовы к незамедлительному вылету для выполнения особых задач. 

# Отряды
- "Последняя надежда"
Отряд сформированный для выполнения особо сложных операций требующих особого подхода, состоит исключительно из Офицеров Титанов. 

- "Падший ангел"
Отряд сформированный из одного сотрудника Офицера Титана, для которого служба Корпорату больше чем работа, это религия, и его святой долг выполнить все что он укажет. 

- "Божья десница"
Отряд сформированный из одного сотрудника Офицера Титана, по совместительству шикарный политик и юрист, отряд сформирован для выполнения операций требующих опытного бойца способного представлять Корпорат. 

- "Слепое дитя"
Отряд сформированный из различного штата сотрудников, они хотят веселья, хотят шоу и операции без особого риска не приносят им удовольствия, и им это не нравится. 

- "Короли тишины"
Отряд сформированный для выполнения скрытных операций, в основном проходящих в темноте, их снаряжение тихое и не оставляющее следов, цель отряда выполнить задачу и не оставить никаких улик. 

- "Грибные шляпки"
Отряд сформированный для выполнения операций проходящих в неблагоприятных условиях, они специалисты РБХ опасностей и их отряд создан для их устранения. 

- "Железные сердца"
Отряд сформированный для выполнения операций проходящих в условиях невозможных для пребывания, восприятия, выполнения задач для сотрудника АнКо, отряд состоит из боевых Рипсоидов различных классов.
